Маяк внутри — маршрут № 5

В архиве: route-5.html, style.css (для локального предпросмотра), assets/ с пятью изображениями.

Для добавления на существующий сайт:
1. Загрузите route-5.html в корень репозитория DomVnutri на ветку, которая публикуется через GitHub Pages.
2. Загрузите пять файлов из assets/ в существующую папку assets/ (не удаляя другие файлы).
3. Файл style.css уже есть на вашем сайте — не заменяйте его без необходимости.
4. Проверьте ссылку https://anopovaanna-ai.github.io/DomVnutri/route-5.html
5. Отдельно нужно обновить карточку пятого маршрута на главной странице, если она пока ведёт на другую страницу.

Важно: сам действующий сайт этим архивом автоматически не обновляется.
